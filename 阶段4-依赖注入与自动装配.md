## Day 1: @Autowired 注解解析

### 核心文件
`spring-beans/src/main/java/org/springframework/beans/factory/annotation/Autowired.java`

### 注解定义

```java
@Target({ElementType.CONSTRUCTOR, ElementType.METHOD, ElementType.PARAMETER, ElementType.FIELD, ElementType.ANNOTATION_TYPE})
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface Autowired {
    boolean required() default true;
}
```

### 关键属性

| 属性 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `required` | boolean | true | 是否必须注入，false表示可选 |

### 使用位置

```java
@Component
public class UserService {

    // 1. 字段注入
    @Autowired
    private UserRepository userRepository;

    // 2. 构造器注入
    @Autowired
    public UserService(OrderRepository orderRepository) {
        this.orderRepository = orderRepository;
    }

    // 3. Setter方法注入
    @Autowired
    public void setProductRepository(ProductRepository repo) {
        this.productRepository = repo;
    }

    // 4. 任意方法注入
    @Autowired
    public void prepare(EmailService emailService, SmsService smsService) {
        // 可以注入多个依赖
    }
}
```

### 三种注入方式对比

| 注入方式 | 优点 | 缺点 | 推荐度 |
|---------|------|------|--------|
| **构造器注入** | 依赖明确，不可变，测试友好 | 参数过多时臃肿 | ⭐⭐⭐ 推荐 |
| **Setter注入** | 可选依赖，可在创建后改变 | 可能忘记注入 | ⭐⭐ 可选 |
| **字段注入** | 简洁，代码量少 | 无法使用final，测试不便 | ⭐ 避免 |

### @Value 注解

```java
@Component
public class AppConfig {

    @Value("${app.name}")
    private String appName;

    @Value("${app.port:8080}")  // 带默认值
    private int port;

    @Value("#{systemProperties['java.version']}")  // SpEL表达式
    private String javaVersion;
}
```

### @Qualifier 注解

```java
@Component
public class OrderService {

    @Autowired
    @Qualifier("mysqlRepository")  // 指定具体bean
    private OrderRepository orderRepository;
}
```

## Day 2: AutowiredAnnotationBeanPostProcessor 核心

### 核心文件
`spring-beans/src/main/java/org/springframework/beans/factory/annotation/AutowiredAnnotationBeanPostProcessor.java`

### 类定位

```java
/**
 * BeanPostProcessor implementation that autowires annotated fields, setter methods,
 * and arbitrary config methods. Such members to be injected are detected through
 * annotations: by default, Spring's {@link Autowired @Autowired} and {@link Value @Value}
 * annotations.
 */
```

**核心作用**：
- 处理`@Autowired`、`@Value`、`@Inject`注解
- 支持构造器、字段、方法注入
- 实现`SmartInstantiationAwareBeanPostProcessor`
- 实现`MergedBeanDefinitionPostProcessor`
- 实现`PriorityOrdered`（高优先级）

### 处理的注解类型

```java
public AutowiredAnnotationBeanPostProcessor() {
    this.autowiredAnnotationTypes.add(Autowired.class);
    this.autowiredAnnotationTypes.add(Value.class);
    try {
        this.autowiredAnnotationTypes.add((Class<? extends Annotation>)
                ClassUtils.forName("jakarta.inject.Inject", AutowiredAnnotationBeanPostProcessor.class.getClassLoader()));
    } catch (ClassNotFoundException ex) {
        // JSR-330 API not available
    }
}
```

### 核心方法

#### 1. postProcessMergedBeanDefinition

```java
@Override
public void postProcessMergedBeanDefinition(RootBeanDefinition beanDefinition, Class<?> beanType, String beanName) {
    // 查找并缓存注入元数据
    InjectionMetadata metadata = findAutowiringMetadata(beanName, beanType, null);
    metadata.checkConfigMembers(beanDefinition);
}
```

**作用**：在bean定义合并后，查找并缓存该bean的所有注入点（字段、方法）。

#### 2. postProcessProperties

```java
@Override
public PropertyValues postProcessProperties(PropertyValues pvs, Object bean, String beanName) {
    // 获取注入元数据
    InjectionMetadata metadata = findAutowiringMetadata(beanName, bean.getClass(), pvs);
    try {
        // 执行注入
        metadata.inject(bean, beanName, pvs);
    } catch (BeanCreationException ex) {
        throw ex;
    }
    return pvs;
}
```

**作用**：在属性填充阶段，执行实际的依赖注入。

### 注入元数据结构

```
InjectionMetadata
    └── Collection<InjectedElement>
            ├── AutowiredFieldElement (字段注入)
            └── AutowiredMethodElement (方法注入)
```

## Day 3: 依赖解析流程

### 依赖查找过程

```java
// AutowiredAnnotationBeanPostProcessor内部调用链
postProcessProperties
    ↓
InjectionMetadata.inject
    ↓
InjectedElement.inject
    ↓
resolveFieldValue / resolveMethodArgument
    ↓
beanFactory.resolveDependency(descriptor, beanName)
```

### DefaultListableBeanFactory.resolveDependency

```java
@Override
@Nullable
public Object resolveDependency(DependencyDescriptor descriptor, @Nullable String requestingBeanName,
        @Nullable Set<String> autowiredBeanNames, @Nullable TypeConverter typeConverter) throws BeansException {

    descriptor.initParameterNameDiscovery(getParameterNameDiscoverer());

    // 1. 处理Optional类型
    if (Optional.class == descriptor.getDependencyType()) {
        return createOptionalDependency(descriptor, requestingBeanName);
    }
    // 2. 处理ObjectProvider（延迟加载）
    else if (ObjectProvider.class == descriptor.getDependencyType()) {
        return new ObjectProviderDependencyFactory().createDependencyProvider(descriptor, requestingBeanName);
    }
    // 3. 处理javax.inject.Provider
    else if (javaxInjectProviderClass == descriptor.getDependencyType()) {
        return new Jsr330Factory().createDependencyProvider(descriptor, requestingBeanName);
    }
    // 4. 处理普通类型
    else {
        // 4.1 使用@Value注解的值
        Object result = getAutowireCandidateResolver().getSuggestedValue(descriptor);
        if (result != null) {
            return convertValueIfNecessary(result, descriptor.getDependencyType(), typeConverter);
        }

        // 4.2 处理多个bean（数组、Collection、Map）
        if (descriptor.getDependencyType().isArray() ||
                Collection.class.isAssignableFrom(descriptor.getDependencyType()) ||
                Map.class == descriptor.getDependencyType()) {
            return resolveMultipleBeans(descriptor, beanName, autowiredBeanNames, typeConverter);
        }

        // 4.3 查找匹配的bean
        Map<String, Object> matchingBeans = findAutowireCandidates(beanName, type, descriptor);

        // 4.4 确定唯一的bean
        if (matchingBeans.size() > 1) {
            autowiredBeanName = determineAutowireCandidate(matchingBeans, descriptor);
        }

        return instanceCandidate;
    }
}
```

### 候选者解析策略

```java
protected String determineAutowireCandidate(Map<String, Object> candidates, DependencyDescriptor descriptor) {
    Class<?> requiredType = descriptor.getDependencyType();

    // 1. 检查是否有@Primary标记的bean
    String primaryCandidate = determinePrimaryCandidate(candidates, requiredType);
    if (primaryCandidate != null) {
        return primaryCandidate;
    }

    // 2. 检查优先级（@Priority注解）
    String priorityCandidate = determineHighestPriorityCandidate(candidates, requiredType);
    if (priorityCandidate != null) {
        return priorityCandidate;
    }

    // 3. 按名称匹配
    for (Map.Entry<String, Object> entry : candidates.entrySet()) {
        String candidateName = entry.getKey();
        Object beanInstance = entry.getValue();
        if (matchesBeanName(candidateName, descriptor.getDependencyName())) {
            return candidateName;
        }
    }

    return null;
}
```

### 解析规则优先级

1. **类型匹配** - 首先按类型查找所有候选者
2. **@Qualifier** - 如果有@Qualifier，按名称筛选
3. **@Primary** - 选择标记为primary的bean
4. **@Priority** - 选择优先级高的（数值小的优先）
5. **按名称匹配** - 最后按字段/参数名称匹配

## Day 4: 构造器注入特殊处理

### 构造器选择策略

```java
/**
 * 选择策略：
 * 1. 如果只有一个构造器，使用它（即使没有@Autowired）
 * 2. 如果有多个@Autowired(required=true)构造器，报错
 * 3. 如果有多个@Autowired(required=false)构造器，选择参数最多的
 * 4. 如果没有@Autowired，使用默认无参构造器
 */
```

### 构造器注入示例

```java
@Component
public class UserService {

    private final UserRepository userRepository;
    private final EmailService emailService;

    // Spring 4.3+：单个构造器可以省略@Autowired
    public UserService(UserRepository userRepository, EmailService emailService) {
        this.userRepository = userRepository;
        this.emailService = emailService;
    }
}
```

### 构造器注入vs字段注入

```java
// 字段注入的问题
@Component
public class FieldInjectionService {
    @Autowired
    private Dependency dependency;  // 可以是null，无法保证不可变性

    // 单元测试时需要反射设置
}

// 构造器注入的优势
@Component
public class ConstructorInjectionService {
    private final Dependency dependency;  // 必须是final，保证不可变性

    public ConstructorInjectionService(Dependency dependency) {
        this.dependency = dependency;  // 编译时检查，不可能为null
    }

    // 单元测试时直接传入mock对象
}
```

### 可选依赖

```java

public class OptionalDependencyService {

    private final RequiredService requiredService;
    private final Optional<OptionalService> optionalService;

    @Autowired
    public OptionalDependencyService(RequiredService requiredService,

```


## 常见问题

### Q1: @Autowired和@Resource的区别？

**A**:
| 特性 | @Autowired | @Resource |
|------|------------|-----------|
| 来源 | Spring | JSR-250标准 |
| 匹配方式 | 先按类型，再按名称 | 先按名称，再按类型 |
|  required | 支持 | 不支持（有name属性） |
| 使用范围 | 字段、方法、构造器、参数 | 字段、方法 |

### Q2: 为什么构造器注入不能用required=false？

**A**: 构造器注入必须在对象创建时提供所有参数。如果某个依赖是可选的，可以使用：
- `Optional<Dependency>`
- `@Nullable`注解
- 多个构造器，一个带@Autowired，一个无参

### Q3: 循环依赖时@Autowired怎么处理？

**A**: @Autowired注入发生在属性填充阶段，此时bean已经实例化，可以通过三级缓存获取早期引用，因此可以解决循环依赖。

**注意**：构造器注入的循环依赖无法解决，因为构造器执行时对象还没创建完成。

### Q4: @Value的值是什么时候解析的？

**A**: @Value的值在postProcessProperties阶段解析，通过`StringValueResolver`解析占位符（如`${app.name}`）和SpEL表达式（如`#{systemProperties['java.version']}`）。

### Q5: 如何自定义@Autowired的行为？

**A**: 可以通过实现`AutowireCandidateResolver`接口自定义候选者解析逻辑，然后通过`ConfigurableListableBeanFactory.setAutowireCandidateResolver()`设置。
