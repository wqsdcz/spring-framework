## Day 1: XML配置解析

### 核心文件
`spring-beans/src/main/java/org/springframework/beans/factory/xml/XmlBeanDefinitionReader.java`

### XML配置示例

```xml
<?xml version="1.0" encoding="UTF-8"?>
<beans xmlns="http://www.springframework.org/schema/beans"
       xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
       xmlns:context="http://www.springframework.org/schema/context"
       xmlns:util="http://www.springframework.org/schema/util"
       xsi:schemaLocation="
           http://www.springframework.org/schema/beans
           https://www.springframework.org/schema/beans/spring-beans.xsd
           http://www.springframework.org/schema/context
           https://www.springframework.org/schema/context/spring-context.xsd">

    <!-- 基础bean定义 -->
    <bean id="userService" class="com.example.UserService">
        <property name="userRepository" ref="userRepository"/>
        <property name="timeout" value="5000"/>
    </bean>

    <!-- 构造器注入 -->
    <bean id="orderService" class="com.example.OrderService">
        <constructor-arg name="orderRepository" ref="orderRepository"/>
        <constructor-arg name="timeout" value="3000"/>
    </bean>

    <!-- 自动装配 -->
    <bean id="paymentService" class="com.example.PaymentService" autowire="byType"/>

    <!-- 抽象父bean -->
    <bean id="baseService" abstract="true">
        <property name="companyName" value="MyCompany"/>
    </bean>

    <!-- 子bean继承 -->
    <bean id="inventoryService" class="com.example.InventoryService" parent="baseService">
        <property name="warehouseLocation" value="Beijing"/>
    </bean>

    <!-- 工厂方法创建 -->
    <bean id="dataSource" class="com.example.DataSourceFactory" factory-method="createDataSource">
        <property name="url" value="jdbc:mysql://localhost:3306/mydb"/>
    </bean>

    <!-- 静态工厂 -->
    <bean id="calendar" class="java.util.Calendar" factory-method="getInstance"/>

</beans>
```

### XmlBeanDefinitionReader核心流程

```java
public int loadBeanDefinitions(Resource resource) {
    // 1. 创建InputSource
    InputSource inputSource = new InputSource(inputStream);

    // 2. 委托给doLoadBeanDefinitions
    return doLoadBeanDefinitions(inputSource, resource);
}

protected int doLoadBeanDefinitions(InputSource inputSource, Resource resource) {
    // 1. 加载XML文档
    Document doc = doLoadDocument(inputSource, resource);

    // 2. 注册bean定义
    return registerBeanDefinitions(doc, resource);
}

public int registerBeanDefinitions(Document doc, Resource resource) {
    // 创建BeanDefinitionDocumentReader
    BeanDefinitionDocumentReader documentReader = createBeanDefinitionDocumentReader();

    // 委托给DefaultBeanDefinitionDocumentReader
    documentReader.registerBeanDefinitions(doc, createReaderContext(resource));
}
```

### BeanDefinitionParserDelegate

```java
/**
 * 解析XML bean定义的核心委托类。
 * 处理所有bean元素：bean、alias、import等。
 */
public class BeanDefinitionParserDelegate {

    // 解析<bean>元素
    public BeanDefinitionHolder parseBeanDefinitionElement(Element ele) {
        // 1. 获取id和name属性
        String id = ele.getAttribute(ID_ATTRIBUTE);
        String nameAttr = ele.getAttribute(NAME_ATTRIBUTE);

        // 2. 解析aliases
        List<String> aliases = new ArrayList<>();
        // ...

        // 3. 创建GenericBeanDefinition
        AbstractBeanDefinition beanDefinition = parseBeanDefinitionElement(ele, beanName, containingBean);

        // 4. 返回BeanDefinitionHolder
        return new BeanDefinitionHolder(beanDefinition, beanName, aliasesArray);
    }

    // 解析bean属性
    public AbstractBeanDefinition parseBeanDefinitionElement(Element ele, String beanName, BeanDefinition containingBean) {
        // 创建GenericBeanDefinition
        GenericBeanDefinition bd = new GenericBeanDefinition();

        // 设置class
        if (ele.hasAttribute(CLASS_ATTRIBUTE)) {
            bd.setBeanClassName(ele.getAttribute(CLASS_ATTRIBUTE));
        }

        // 设置parent
        if (ele.hasAttribute(PARENT_ATTRIBUTE)) {
            bd.setParentName(ele.getAttribute(PARENT_ATTRIBUTE));
        }

        // 解析其他属性：scope、lazy-init、autowire等
        parseBeanDefinitionAttributes(ele, beanName, containingBean, bd);

        // 解析子元素：constructor-arg、property、qualifier等
        parseMetaElements(ele, bd);
        parseConstructorArgElements(ele, bd);
        parsePropertyElements(ele, bd);
        parseQualifierElements(ele, bd);

        return bd;
    }
}
```

### 命名空间处理

```java
// 处理自定义命名空间（如context:component-scan）
public BeanDefinition parseCustomElement(Element ele) {
    // 获取命名空间URI
    String namespaceUri = getNamespaceURI(ele);

    // 查找对应的NamespaceHandler
    NamespaceHandler handler = this.readerContext.getNamespaceHandlerResolver().resolve(namespaceUri);

    // 委托给NamespaceHandler解析
    return handler.parse(ele, new ParserContext(this.readerContext, this, containingBd));
}
```

### 常用命名空间

| 命名空间 | 处理器 | 功能 |
|---------|--------|------|
| context | ContextNamespaceHandler | 组件扫描、属性占位符 |
| util | UtilNamespaceHandler | 集合类型定义 |
| aop | AopNamespaceHandler | AOP配置 |
| tx | TxNamespaceHandler | 事务配置 |

## Day 2: Properties配置

### 核心文件
`spring-beans/src/main/java/org/springframework/beans/factory/support/PropertiesBeanDefinitionReader.java`

### Properties配置格式

```properties
# bean名称.(class|abstract|parent|lazy-init|...)
userService.class=com.example.UserService
userService.property.userRepository(ref)=userRepository
userService.property.timeout=5000

# 构造器参数
orderService.class=com.example.OrderService
orderService.constructor-arg.0(ref)=orderRepository
orderService.constructor-arg.1=3000

# 父bean
baseService.class=com.example.BaseService
baseService.abstract=true
baseService.property.companyName=MyCompany

# 子bean
inventoryService.parent=baseService
inventoryService.class=com.example.InventoryService
inventoryService.property.warehouseLocation=Beijing
```

### 使用PropertiesBeanDefinitionReader

```java
DefaultListableBeanFactory factory = new DefaultListableBeanFactory();
PropertiesBeanDefinitionReader reader = new PropertiesBeanDefinitionReader(factory);

// 从文件加载
reader.loadBeanDefinitions(new ClassPathResource("beans.properties"));

// 或从Properties对象加载
Properties props = new Properties();
props.setProperty("myBean.class", "com.example.MyBean");
reader.registerBeanDefinitions(props);

// 获取bean
MyBean myBean = factory.getBean(MyBean.class);
```

### Properties vs XML

| 特性 | Properties | XML |
|------|------------|-----|
| 可读性 | 一般 | 好 |
| 结构支持 | 弱 | 强（嵌套元素）|
| 命名空间 | 不支持 | 支持 |
| IDE支持 | 弱 | 好（Schema验证）|
| 使用场景 | 简单配置 | 复杂配置 |

**注意**：Properties配置方式现在很少使用，主要用于简单的场景或遗留系统。

## Day 3: Groovy DSL配置

### 核心文件
`spring-beans/src/main/java/org/springframework/beans/factory/groovy/GroovyBeanDefinitionReader.java`

### Groovy配置示例

```groovy
// beans.groovy
import com.example.*

beans {
    // 基础bean定义
    userService(UserService) {
        userRepository = ref('userRepository')
        timeout = 5000
    }

    // 单例简写
    userRepository(UserRepository)

    // 使用闭包配置
    orderService(OrderService) { bean ->
        bean.scope = 'prototype'
        bean.initMethod = 'init'
        orderRepository = ref('orderRepository')
    }

    // 属性是集合
    configService(ConfigService) {
        configList = [1, 2, 3]
        configMap = [key1: 'value1', key2: 'value2']
    }

    // 导入其他配置
    importBeans('classpath:datasource.groovy')
}
```

### 使用GroovyBeanDefinitionReader

```java
DefaultListableBeanFactory factory = new DefaultListableBeanFactory();
GroovyBeanDefinitionReader reader = new GroovyBeanDefinitionReader(factory);

// 从文件加载
reader.loadBeanDefinitions(new ClassPathResource("beans.groovy"));

// 或从字符串加载
String groovyScript = """
    beans {
        myBean(MyBean) {
            name = 'test'
        }
    }
""";
reader.loadBeanDefinitions(new ByteArrayResource(groovyScript.getBytes()));
```

### Groovy DSL的优势

| 优势 | 说明 |
|------|------|
| 简洁 | 比XML更简洁 |
| 灵活 | 支持Groovy的闭包、集合等特性 |
| 类型安全 | 编译时检查 |
| 可编程 | 支持条件逻辑、循环等 |

### 条件配置示例

```groovy
import org.springframework.core.env.Environment

beans {
    // 根据环境变量决定创建哪个bean
    if (environment.acceptsProfiles('dev')) {
        dataSource(H2DataSource) {
            url = 'jdbc:h2:mem:test'
        }
    } else {
        dataSource(MySQLDataSource) {
            url = 'jdbc:mysql://prod-server/mydb'
        }
    }

    // 循环创建多个bean
    ['service1', 'service2', 'service3'].each { name ->
        "$name"(GenericService) {
            serviceName = name
        }
    }
}
```

## Day 4: 配置方式对比

### 三种方式对比

| 特性 | XML | Properties | Groovy DSL |
|------|-----|------------|------------|
| 语法 | 标签 | key=value | Groovy闭包 |
| 学习曲线 | 中 | 低 | 中 |
| 灵活性 | 中 | 低 | 高 |
| 类型安全 | 无 | 无 | 有 |
| IDE支持 | 好（Schema）| 弱 | 中 |
| 动态配置 | 不支持 | 不支持 | 支持 |
| 使用场景 | 传统项目 | 简单配置 | 复杂动态配置 |

### 现代Spring推荐使用

```java
// 1. Java Config（最推荐）
@Configuration
public class AppConfig {
    @Bean
    public UserService userService() {
        return new UserService();
    }
}

// 2. 组件扫描
@Configuration
@ComponentScan("com.example")
public class AppConfig {
}

// 3. @PropertySource加载配置
@Configuration
@PropertySource("classpath:app.properties")
public class AppConfig {
    @Value("${app.name}")
    private String appName;
}
```

### 配置加载完整示例

```java
public class ConfigurationDemo {
    public static void main(String[] args) {
        // 1. 创建容器
        AnnotationConfigApplicationContext context =
            new AnnotationConfigApplicationContext();

        // 2. 加载XML配置
        XmlBeanDefinitionReader xmlReader = new XmlBeanDefinitionReader(context);
        xmlReader.loadBeanDefinitions("classpath:beans.xml");

        // 3. 加载Properties配置
        PropertiesBeanDefinitionReader propReader =
            new PropertiesBeanDefinitionReader(context);
        propReader.loadBeanDefinitions("classpath:beans.properties");

        // 4. 加载Groovy配置
        GroovyBeanDefinitionReader groovyReader =
            new GroovyBeanDefinitionReader(context);
        groovyReader.loadBeanDefinitions("classpath:beans.groovy");

        // 5. 注册Java Config
        context.register(AppConfig.class);

        // 6. 刷新容器
        context.refresh();

        // 7. 使用bean
        UserService userService = context.getBean(UserService.class);
    }
}
```

## 常见问题

### Q1: XML配置中的命名空间是如何解析的？

**A**: 通过`spring.handlers`和`spring.schemas`文件：
- `spring.handlers`：映射命名空间URI到NamespaceHandler类
- `spring.schemas`：映射命名空间URI到XSD文件位置

### Q2: 为什么现在很少使用Properties配置？

**A**:
- 表达能力有限，无法表示复杂结构
- 不支持命名空间扩展
- 不支持集合类型
- 现代Spring更推荐Java Config和注解

### Q3: Groovy DSL适合什么场景？

**A**:
- 需要动态生成配置的场景
- 团队熟悉Groovy的项目
- 需要条件判断、循环等逻辑的配置
- 与Grails框架集成

### Q4: 多种配置方式可以混合使用吗？

**A**: 可以。Spring支持混合使用：
- XML中导入Java Config：`<context:component-scan/>`
- Java Config中导入XML：`@ImportResource`
- 同时加载XML、Properties、Groovy配置

### Q5: 配置文件中的占位符${...}是如何解析的？

**A**: 通过`PropertyPlaceholderConfigurer`或`PropertySourcesPlaceholderConfigurer`：
- 从properties文件加载配置
- 替换XML/注解中的占位符
- 支持默认值：`${app.name:defaultName}`
